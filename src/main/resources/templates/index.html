⚡ Quick Examples

📝 Get all students:
curl -u user:password http://localhost:8080/api/students
✨ Create student (Admin):
curl -u admin:password -X POST http://localhost:8080/api/students -H "Content-Type: application/json" -d '{"firstName":"John","lastName":"Doe","email":"john@example.com"}'
